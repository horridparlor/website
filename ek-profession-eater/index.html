1) Define Rules

Each rule has a name and a list of options. Every option has a code (appended to the base code) and a name (shown in the caption). You can order rules; order affects code concatenation & caption order.

2) Add Base Profession Rows

Select which rules to apply. Checked rules will expand into all combinations of their options on submit. Checkboxes remain as-is after submit; only code & name clear.

Bulk paste (TAB-separated)

Paste lines as code⇥name. Header code⇥name is optional. Only TAB splits columns; commas and other characters in the name are kept as-is. Preview shows fully expanded rows with the currently checked rules.
